Install the Agent

  1. Store the credentials in the Cluster

    Run this against prod-singapore.

    Shell 
    kubectl create namespace reinhardt-cloud-agent
kubectl -n reinhardt-cloud-agent create secret generic agent-credentials \
  --from-literal=client_id=cl_01JB8Q4V7M2XK9R3TNE5D6WFHA \
  --from-literal=client_secret=rcs_Zk3mV8qPd2YxN7aTb4LwHc9RfJ6uSe1G

  2. Install the Agent chart

    The chart reads the credentials from the Secret you just created.

    Shell 
    helm install reinhardt-cloud-agent ./charts/reinhardt-cloud-agent \
  --namespace reinhardt-cloud-agent \
  --set controlPlane.url=https://cloud.acme-robotics.example \
  --set controlPlane.clusterName=prod-singapore \
  --set auth.existingSecret=agent-credentials

  3. Wait for the Agent to connect

    This page doesn't need to stay open. You can check the Agent's state on the Cluster page at any time.
